# Gaurika Pareek — Portfolio

Plain Vite + React + Tailwind CSS v4. No framework lock-in.

## Local
```
npm install
npm run dev
```

## Deploy on Netlify (one click)
1. Push this folder to a new GitHub repo.
2. Netlify → "Add new site" → "Import from Git" → pick the repo.
3. Build settings auto-detected from `netlify.toml`:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. Click **Deploy**. Done.

Or drag-and-drop: run `npm run build` locally, then drop the `dist/` folder onto https://app.netlify.com/drop
